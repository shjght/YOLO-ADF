## 3. 正式实验四步

### 3.1 生成标签（约 1-3 分钟，取决于磁盘速度）

```bat
python build_labels.py
```

**预期输出**：解析两个 json，train 保留约 5.7-6.3 万帧、val 保留 8193 帧
（clear 3441 / night 3929 / rain 396 / snow 422 / **fog 5**）。
会打印一句 fog 稀缺的提示——这是数据集性质，正常，论文里如实报告。
若 train 保留数只有一两千 → 说明只探测到本地子集，检查 `C:\Users\KUST\xl\bdd100k_final\images\100k\train` 是否是全量。

产物：`labels_bdd.csv`（训练直接读它）。

### 3.2 训练（单卡 3090，约 15-40 分钟）

cmd：
```bat
set CUDA_VISIBLE_DEVICES=0 && python train.py --model mobilenet_v3_small
```
PowerShell 则用：
```powershell
$env:CUDA_VISIBLE_DEVICES="0"; python train.py --model mobilenet_v3_small
```

**预期**：每 epoch 打一行，loss 下降、val_acc 升到 **0.93-0.97** 后收敛。
开头会打印类别权重（fog 权重最大，正常）。
结束生成 `weights\weatherclf_mobilenet_v3_small_best.pt` + `trainlog_*.json`。

显存不够（不应该）就加 `--bs 128`。不要改 `--seed`（论文约定 seed 0）。

### 3.3 基准评测（约 3-5 分钟）

```bat
python benchmark.py --model mobilenet_v3_small --cpu-latency
```

**预期输出（当场 sanity check）**：
- `[BDD val, in-domain] acc ≈ 0.93-0.97`，night 的 recall 应最高（≥0.98）
- fog 类 val 只有 5 帧，P/R 数字难看是**正常的**，忽略
- `[ACDC val, cross-domain] n=400, acc ≈ 0.80-0.88`；**每类 n 必须是 100**
  （fog/rain/snow/night 各 100，clear n=0）——不是 100 说明 ACDC 目录有出入，
  停下来拍照发我
- ACDC 雾天 recall 可能偏低（BDD 雾=薄霾、ACDC 雾=浓雾）——预期内，不慌，
  雾场景对分支选择不敏感，不影响 WADI
- `[latency GPU] FP16 ≈ 0.3-0.6 ms`；CPU 延迟会明显慢（几分钟），正常

产物：`results\benchmark_mobilenet_v3_small.json`（含混淆矩阵+逐图预测）+ `results\table_*.md`。

### 3.4 计算 realized WADI（几秒钟，无需 GPU）

```bat
python compute_wadi_real.py
```

**预期输出**：oracle WADI 必须是 **0.4806**（不对 = table3.csv 被动过，发我）；
然后打印 aggressive / conservative 两种路由下的 realized WADI + bootstrap 95% CI。
conservative 的 realized 大概率在 **0.46-0.48**、保留率 95% 以上。
产物：`results\wadi_real.json`。

## 6. 常见问题

| 症状 | 处理 |
|---|---|
| `Could not locate dataset root` | 数据不在 `C:\Users\KUST\xl\bdd100k_final`，改用 `python build_labels.py --data-root <bdd所在目录>` |
| `Could not locate ACDC` | ACDC 目录结构不是 `ACDC\rgb_anon\fog\val\...`，用 `python benchmark.py --acdc-root <ACDC所在目录>` |
| ACDC 某类 n≠100 或为 0 | 该条件 val 布局与预期不同，把目录树截图发我，别硬跑 |
| `image-missing-on-disk` 特别多 | 标签 json 里的图不在被探测的图像目录，用 `--extra-train-dirs "路径1,路径2"` 补充 |
| 下载相关报错 | 两台机器都不需要下载；`download_bdd100k.py` 仅新机器保底 |
| 其他任何报错 | 截图/复制完整报错信息发我，不要自己改代码 |

## 7. 红线（不要做的事）

1. **不要在 ACDC 上训练任何东西**（只评估——跨域协议不能污染）；
2. **不要改 `--seed`**（论文约定 seed 0）；
3. **不要动检测器代码和权重**（本实验与 YOLO-ADF 训练完全无关）;
4. 不要并行占 4 张卡跑这个（单卡足够，别耽误别人的检测任务）。
